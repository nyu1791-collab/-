# つづける — 習慣化アプリ

毎日の習慣を記録して、続ける力を育てるシンプルなアプリです。
バックエンド不要、ブラウザだけで動作します。

## 機能

- **習慣の追加・削除** — やりたい習慣を自由に登録
- **ワンタップでチェックイン** — 今日の達成を丸ボタンで記録
- **ストリーク（連続記録）** — 何日連続で続いているかを表示
- **週間ビュー** — 直近7日間の達成状況を一目で確認
- **サマリー** — 今日の達成数・達成率・最長ストリーク
- **ダーク／ライトテーマ** — ワンタップで切り替え（設定は保存）
- **自動保存** — データはブラウザの `localStorage` に保存（外部送信なし）

## 使い方

ビルド不要です。`index.html` をブラウザで開くだけで動きます。

```bash
# どちらでもOK
open index.html

# もしくは簡易サーバーで
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル・テーマ（CSS変数） |
| `app.js` | ロジック・データ保存（依存ライブラリなし） |

## データについて

すべてのデータは利用中のブラウザ内にのみ保存されます。
サーバーには一切送信されません。別のブラウザや端末とは同期されません。
