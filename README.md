# つづける — 習慣化＆朝チャレンジ

毎日の習慣を記録して、続ける力を育てるアプリです。
寝坊にはお金のペナルティをかける「朝チャレンジ」付き。
バックエンド不要、ブラウザだけで動作し、**ホーム画面に追加（インストール）**できます。

## 楽しく続ける仕掛け

- ☀️ **育成マスコット「ひだまり」** — 連続記録で卵から太陽神まで成長。今日の状況で表情や言葉が変わる相棒
- 👋 **はじめての案内** — 初回起動でやさしくオンボーディング。習慣を選んで起床時刻を決めるだけで開始
- 🗓️ **達成カレンダー** — 月ごとのヒートマップで「続いている実感」を可視化（前月へさかのぼり可）
- 📊 **統計ページ** — 最長記録・総チェック・守ったお金・30日トレンドグラフ・実績バッジ（`stats.html`）
- 🔔 **リマインダー通知** — 起床／習慣の時刻に通知（アプリを開いている間に発火。設定は朝チャレンジ画面）
- 🛬 **紹介ページ** — 特徴と画面イメージをまとめたランディング（`landing.html`）
- 💾 **エクスポート/インポート** — 記録をJSONで書き出し・復元、端末間移行（統計ページ）
- 📸 **スクショ撮影スタジオ** — ストア用スクリーンショットを作る撮影ページ（`shots.html`）
- 📳 **触覚フィードバック** — チェックや起床確認で軽くバイブ（対応端末）
- 📲 **PWA対応** — ホーム画面に追加してアプリのように起動、オフラインでも動作
- ⭐ **レベル＆XP** — 習慣のチェックや早起きでXPが貯まり、称号がアップ（ねぼすけ見習い → 太陽神）
- 🎉 **達成演出** — チェック時に紙吹雪＋効果音、連続記録の節目（3/7/14/30/50/100日…）で大きく祝福
- 📣 **シェアカード** — 連続記録やレベルを画像にしてSNSへ（Web Share API、未対応環境では画像保存）
- 🔊 **効果音のオン／オフ** — ワンタップで切り替え（依存ライブラリなし・WebAudio）

### ⚔️ ミニゲーム「ゆるレンジャー」（`rangers.html`）

息抜き用の本格ミニゲーム。横スクロール型のディフェンスバトルです。

- 🏰 **とりで防衛バトル** — マナをためてユニットを召喚し、敵のとりでを撃破
- 🐾 **個性ゆたかなユニット** — 近接のみけ／弓のうさ／盾やくぽち／回復のもこ／範囲魔法のふく／ふっとばしのくま。**ステージを進めると仲間が増える**
- ⚡ **マナ強化** — 戦闘中にマナの回復速度と上限をアップグレードする駆け引き
- ☄️ **必殺メテオ** — クールダウン制の全体攻撃で窮地をしのぐ
- 🗺️ **全12ステージ** — じわじわ強くなる敵、ラッシュ襲来、最後はボス「まおうグラル」との一騎打ち
- 🌀 **エンドレスモード** — 破壊不能のポータルから湧き続ける敵をどこまで守れるか。ベスト記録を保存
- ⭐ **スター評価＆ゴールド** — とりでの残り体力で3段階評価、報酬でユニットをレベルアップ
- 🏅 **実績ずかん** — 「まおう討伐」「スターコレクター」など9種のバッジと通算統計
- 👋 **チュートリアル** — 初回バトルでたいちょうが遊び方を案内
- 🎵 **BGM＆効果音** — WebAudioのチップチューン。ON/OFF設定を保存
- 🎥 **カメラ操作** — 前線を自動追従、ドラッグで戦場を見渡せる
- ⏩ **倍速・ポーズ・キーボード操作対応** — 依存ライブラリなし（Canvas + WebAudio + localStorage）

#### 🎰 ガチャ＆コレクション

- **★1〜★3のガチャ** — 🔮ジェムを集めてヒーローを引く。10連は★2以上を1体保証、★3確定の天井（50連）つき
- **★3はスキルを習得** — 「りゅうせんぷう（範囲攻撃化）」「せいなるうた（回復オーラ）」「まりょくかいほう（攻撃UPオーラ）」「ふくつのまもり（被ダメ減）」「ひっさつのいちげき（クリティカル）」「じばく（戦死時に大爆発）」
- **限界突破** — 重複ヒーローでステータス強化
- **23体のヒーロー図鑑** — 基本6体＋ガチャ17体。タップでデッキ編成（最大6体）
- **デッキはぼうけんでも使える** — 編成したチームでストーリー・エンドレス・アリーナすべてを戦う。ゴールド強化はぼうけんに反映
- **全員描き分け** — はちまき・眼帯・マント・天使の輪・忍びマスク・ゴーグルなどの装飾と、ドラゴン／ペンギンの固有ボディで1体ずつ見た目が違う

#### 🏟️ アリーナ（PvP・オンライン対戦／バックエンド不要）

- **デッキ対戦** — 自分の編成 vs 相手の編成。AIが相手チームを操作し、あなたはリアルタイムで召喚して戦う
- **シェアコード／リンクで対戦** — 自分のチームを**コードやURLで共有**。友だちがリンクを開くと、あなたのチームに挑戦できる（サーバー不要、`localStorage` だけで成立）
- **ランクマッチ** — ランクに応じて強くなるCPUライバルと対戦し、ビギナー→レジェンドへ昇格
- **公平性の担保** — シード付き乱数で戦闘を再現可能にし、同条件なら結果が完全一致

#### 🧪 品質

- **ヘッドレス自動テスト** — `node tools/rangers-smoke.js` で全12ステージのバランス、ガチャ排出率・天井、対戦コードの往復、アリーナの決定論、★3スキルの動作までを機械検証（全27チェック）

## 機能

- **習慣の追加・削除** — やりたい習慣を自由に登録
- **ワンタップでチェックイン** — 今日の達成を丸ボタンで記録
- **ストリーク（連続記録）** — 何日連続で続いているかを表示
- **週間ビュー** — 直近7日間の達成状況を一目で確認
- **サマリー** — 今日の達成数・達成率・最長ストリーク
- **ダーク／ライトテーマ** — ワンタップで切り替え（設定は保存）
- **自動保存** — データはブラウザの `localStorage` に保存（外部送信なし）

### ⏰ 朝チャレンジ（`morning.html`）

寝坊にお金のペナルティをかけるコミットメント装置です。

- 目標の起床時刻を設定し、その時刻を過ぎると **遅刻1分ごとにペナルティが加算**（例：100円／分）
- **1日の上限**を設定でき、そこで頭打ち（例：上限1000円なら10分で最大）
- 「起きた！」を押し **寝ぼけ防止の計算3問**に正解した時点で加算が止まり、その日の額が確定
- 一度も起きられなかった日は上限額で確定し、**未払い残高**として積み上がる
- 設定した **支払いリンク**（Stripe／PayPay／Kyash 等）から実際の支払いページへ
- ※ブラウザが自動でカード決済することはありません（残高記録＋支払い導線）

## 使い方

ビルド不要です。`index.html` をブラウザで開くだけで動きます。

```bash
# 簡易サーバーで開くのがおすすめ（インストール/オフラインに必要）
python3 -m http.server 8000
# → http://localhost:8000 を開く

# 単に動かすだけなら index.html を直接ブラウザで開いてもOK
# （ただし PWA インストール・オフライン機能は http(s) でのみ有効）
open index.html
```

> アイコンを作り直したいときは `node tools/generate-icons.js` を実行すると
> `icons/icon-192.png` と `icons/icon-512.png` が再生成されます。

## 公開用の素材

- **OG/シェア画像**：`icons/og.png`（1200×630）。`node tools/generate-og.js` で再生成できます。
- **スクリーンショット**：`shots.html` を開くと、デモデータ入りの画面が縦長パネル（540×1170）で並びます。
  ブラウザのデバイスツールバーを2倍(DPR)にして各パネルを撮影すると、1080×2340相当のストア用画像になります。
- **データのバックアップ**：統計ページの「データのバックアップ」からJSONをエクスポート/インポートできます。

## データについて

すべてのデータは利用中のブラウザ内にのみ保存されます。
サーバーには一切送信されません。別のブラウザや端末とは同期されません。
